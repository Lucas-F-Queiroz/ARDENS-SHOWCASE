# Publishing checklist

Before making this showcase public:

1. Create a new public repository named `ARDENS`.
2. Do **not** initialize it with a license that grants redistribution rights to the game source/assets.
3. Copy the files from this showcase package.
4. Add 2–4 current screenshots to `assets/screenshots/`.
5. Replace the placeholder before/after paths in the README when those images exist.
6. Add at least one short GIF to `assets/gifs/` after the visual rework has something worth showing.
7. Keep the production Unity repository private.
8. Review every code sample before publishing it.
9. Do not publish Asset Store content, licensed fonts/audio, credentials or internal tooling secrets.
10. Pin the public `ARDENS` repository on the GitHub profile.
